# CBT 净收益计算

跨境店商品列表中的“净收益”不能按商品售价直接估算。以 Global Selling 后台为准，其金额应按同一站点、同一物流方案、同一促销状态计算：

`净收益 = 商品链接价格 - 销售费 - 卖家承担的国际物流费 - 进口/税费承担额 - 活动/折扣承担额 - 其他官方调整`

## 已验证的来源

- `GET /marketplace/items/{CBT_ITEM_ID}`：商品 USD 售价、销量、库存、刊登类型、物流状态、质保、图片、类目。
- `GET /sites/CBT/listing_prices?...`：可访问，但 CBT 父类目的 `sale_fee_amount` 当前返回 `0`，不能作为 Global Selling 后台显示的实际销售费。

## 显示规则

- 未取得同一市场的官方销售费、物流报价和税费时，ERP 必须显示“待官方报价”，不得以零费用计算净收益。
- 后续需要接入 Global Selling 对应的费用/物流报价或结算明细接口，并记录报价时间、市场、价格、包装规格和促销上下文。
